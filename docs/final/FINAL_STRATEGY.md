## 排位賽正式規則（[rules/排位賽規則_20261006.pdf](../../rules/排位賽規則_20261006.pdf)，2026/10/06 初版；英文版內容一致）

TASA 競賽頁「文件下載」區已經公布，主辦方沒另外通知。**規則有修訂會更新同一頁，賽前要再看一次。**

- **每棒 ≤ 250 m/s**（初賽是 1500），超過 250 + 1e-5 m/s 就**失格、不列入排名**。
- **總 Δv ≤ 3 km/s**，超過就失格。
- 攔截前軌跡穿越地球就失格。
- 兩棒間隔 < 100 s：每次扣 10 分（不失格）。第一棒可在 t = 0。
- 攔截成功：Δr ≤ 5 km。T_max = A 通過近地點後地心距離首次回到「任務邊界」的時刻，比賽開始才公布。
- 計分：`Score = 50·exp(−(Δr_min − 5)/100) + 25/(1+e^{k_t(T_team−C_t)}) + 25/(1+e^{k_v(ΔV_team−C_v)}) − ΣP_n`，參數當場公布。
  **沒攔到還有部分分數**（差 50 km 仍有約 32 分），所以任何情況都要交出一份合法解。
- 同分比序：d_min 小者優先 → ΔV 小 → T 短 → 5 分鐘簡報 → 指導老師有出席者優先。
- **外界擾動全開**：EGM96 20×20、潮汐 SolidAndPole、NRLMSISE00 大氣＋SPADFile 阻力、太陽／月球引力、SRP（SPADFile）、相對論效應。
- 以主辦驗證程式為準；結果無法重現會被取消成績。
- **決賽隊員必須全員到齊**。
- 晉級名單公布 9 隊（15、18、19、20、22、24、35、52、54）。

## 判斷

- 排位前二保底 30,000，三、四名最多 10,000，差 20,000 以上 → 資源全押排位賽。
- **現有工具不符新規則，這是最大的風險**（初賽 98.32 那套直接拿去會失格或打不到）：
  1. 每棒 cap 250 → 幾 km/s 的任務要 8–12 棒以上；拆棒器是為「少數棒稍微超標」設計的。
  2. 沒有總 Δv ≤ 3 km/s 的硬限制。
  3. Python 端只有點質量／J2–J4 zonal，GMAT 腳本也寫死 Drag=None、SRP=Off、Order=0。全擾動下 Python 解在 GMAT 裡會偏掉（推估 km 級以上）。
- 對策：**Python 只負責找路線（初始猜值），最後命中改由 GMAT 在全擾動模型下用 DC 修正**，再把收斂後的燃燒值寫死成固定燃燒版本繳交（可重現）。
