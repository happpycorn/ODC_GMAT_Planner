## 四、每回合怎麼玩

用 [organizer.py](organizer.py) 當主辦。**這份的對手會看你出招**：每回合由我們的 agent 依當下狀態即時出手
（你選躲方 → 對手 capture_pursuer；你選追方 → 對手 safe_evader）。

1. GUI「每回合」頁（或 CLI `advise`）拿到提交行，手寫，按「已交出」。
2. 在 `medal/` 跑 organizer，把到目前為止每回合你們交的 Δv 依序列出（例：交完第 2 回合）：
   ```bash
   .venv/bin/python ../docs/final/mock_drill_close_20261107/organizer.py --role evader --our-dv=<第1回合X,Y,Z> --our-dv=<第2回合X,Y,Z> --out <day 資料夾>/round2_end.csv
   ```
   負數開頭要寫成 `--our-dv=-2.6180,...`（有等號）。每次跑約 5–10 秒（對手要重算）。
3. 把寫出的 CSV 拖進 GUI（CLI：`announce day/session.json --state <檔>`）。
4. 用 GUI 測試時，`ODC_DAY_DIR` 指到暫存資料夾，不要弄髒 `medal/day/`。
5. 對手種子預設 1。想再打一場不同的對手：加 `--opp-seed 0`（或 2、3…），並換一個 `--out` 資料夾（對手紀錄 `organizer_log.json` 放在 `--out` 同資料夾）。
