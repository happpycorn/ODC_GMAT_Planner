# 對手每回合 Δv（主辦公告值）

**每回合交出提交行之後才看那一列。** 單位 m/s、EarthMJ2000Eq。只看你們對手那一張表。

對手的 Δv 是事先錄好的（我們自己的追方 capture_pursuer 對躲方 safe_evader 打一場、記下雙方每回合的推力），不會因為你們怎麼推而改變。
二體下每艘船的軌道只跟自己的推力有關，所以這張表在你們怎麼推都成立；只是對手不會「看你出招」，比真的比賽好打。
