## 第一場：排位賽（60 分鐘，計時開始就是 10:45）

### 一、任務

外星飛行器 SC_Alien 沿雙曲線軌道接近地球，SC_Human 從低地球軌道出發攔截。

### 二、題目 Script（USB 檔）

檔案：[usb/ranking/RankingRound_Problem.script](usb/ranking/RankingRound_Problem.script)。當天把它當成 USB 上拿到的檔，複製到英文路徑。

兩艘的初始狀態、任務起始曆元、太空船物理參數都在 Script 裡；**主辦不另外公布六根數**，初始狀態只給 EarthMJ2000Eq 的位置速度（km、km/s）。

### 三、任務邊界

SC_Alien 通過近地點後，第一次離開**高度 60,000 km** 時任務結束（T_max）。主辦不另外公布秒數。

### 四、計分參數

| 參數 | 值 |
|---|---|
| k_t | 6.0 × 10⁻⁵ s⁻¹ |
| C_t | 11.5 小時 |
| k_v | 2.2 (km/s)⁻¹ |
| C_v | 1.75 km/s |
| C_r | 40 km |

不提供參考解。

### 五、限制（同 11-04 修訂版規則）

單次 ΔV ≤ 250 m/s、總 ΔV ≤ 3 km/s、兩次機動間隔 ≥ 100 s、攔截前不得穿越地球、攔截判定 Δr ≤ 5 km。

## 第二場：金牌賽（每回合 10 分鐘 × 6）

### 一、公告規則

| 項目 | 值 |
|---|---|
| 單發上限 ΔV_lim（兩方相同） | **0.2 km/s** |
| 捕獲半徑 R_cap | 8 km |
| 每回合滑行 T_round | **15 分鐘** |
| 回合數 | 6 |
| 安全空域 | 逃方第 6 回合結束時的半長軸，換算成高度（a − 6378.137 km）落在 **1,050 – 1,110 km** |
| 力學 | 純二體 |

### 二、初始狀態（USB 檔）

檔案：[usb/medal/initial_state.csv](usb/medal/initial_state.csv)（EarthMJ2000Eq，km、km/s）。當天把它當成 USB 上拿到的檔，複製到 `medal/day/`。

- **SC_Red 是追方，SC_Blue 是逃方。**
- 兩艘的 epoch 不一樣，以晚的那艘為第 1 回合起點。

### 三、選角色

你們是排位賽第 1 名，有選擇權。公告後 10 分鐘內決定。

### 四、每回合怎麼玩

一個人模擬時沒有對手，用 [OPPONENT_MOVES](OPPONENT_MOVES.md) 當主辦公告的對手 Δv：

1. 照手冊 `advise`，手寫提交行。
2. 寫好後才打開 OPPONENT_MOVES 對應回合那一列，那就是主辦公告的對手實際 Δv。
3. `announce` 填對手 Δv 和你自己交的 Δv，**不加 `--state`**（這次沒有主辦發的每回合狀態檔，工具自己推）；下一回合 `advise` 也不加 `--state`。
