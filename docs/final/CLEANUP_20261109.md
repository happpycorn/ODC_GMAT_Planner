兩個目的：

1. **檔案不交錯**：彩排、測試留下的解、設定檔、狀態檔全部搬走，當天資料夾裡只會有今天產生的東西，交件時不會拿錯。
2. **合規**：排位賽與四強賽禁止網路和生成式 AI（**含離線模型**），全程巡查、違規取消成績（11-08 主辦來信）。Mac 上不能有 AI 程式在跑。

順序：一～三在**彩排做完、睡前**做；四在**出門前**做；五在**會場就位後**做。每節最後都有一條檢查，印出來的跟寫的一樣才算完成。
全部只「搬走」不刪除，搬到 `~/Documents/Program/ODC_archive_pre1109/`，賽後要找都還在。

指令都在專案根目錄執行：

```bash
cd ~/Documents/Program/ODC_Program
```

## 一、git：先處理還沒 commit 的改動

```bash
git status --short
```

- 什麼都沒印 → 下一節。
- 有改動：先確認是不是**今晚彩排用的版本**。是就 commit（金牌賽 GUI 的 11-07 改動就屬於這種），不是就 `git stash -u` 收起來。
  不要帶著一堆 `M`、`??` 進比賽，出事時會分不清是哪一版。
- commit 完再做一次 USB 的 git bundle（第三節），bundle 才會是最新版。

檢查：`git status --short` 沒有輸出，`git log -1 --oneline` 是你預期的那個 commit。

## 二、排位賽與金牌賽的檔案清場

彩排的 `rank-1` 留著，當天步驟 5 會直接報錯（`--run-dir` 不能已存在）；舊的 `ranking.json` 留著，`new-config` 不會覆蓋，會拿到舊題目的根數。金牌賽的 `day/` 留著，GUI 會混到舊的狀態檔與提交紀錄。

```bash
A=~/Documents/Program/ODC_archive_pre1109/cleanup_$(date +%m%d_%H%M); mkdir -p "$A/outputs" "$A/configs_local" "$A/medal"
find outputs -mindepth 1 -maxdepth 1 ! -name .DS_Store -exec mv {} "$A/outputs/" \;
find configs/local -mindepth 1 -maxdepth 1 ! -name config.json -exec mv {} "$A/configs_local/" \;
find medal -maxdepth 1 -name 'day*' -exec mv {} "$A/medal/" \;
[ -d medal/runs ] && find medal/runs -mindepth 1 -maxdepth 1 -exec mv {} "$A/medal/" \;
echo "搬到 $A"
```

`docs/final/mock_drill_*` 是彩排題目與答案，是文件，留著不動（真的狀態檔只會放進 `medal/day/`）。

再看桌面和下載資料夾有沒有舊的繳交件或狀態檔，有就一起搬走：

```bash
ls ~/Desktop ~/Downloads | grep -iE "submit|report|\.script|initial|state|round|ODC" 
```

檢查：

```bash
ls -A outputs | grep -v .DS_Store; ls configs/local; ls -d medal/day* 2>/dev/null
```

只印出 `config.json` 一行才算完成。

## 三、USB 清場

兩支 USB 都做。舊的彩排繳交件留在 USB 上，是最容易交錯的地方。

1. 把 USB 上除了 `ODC_Final/` 以外的東西搬到 Mac 的封存資料夾（`$A/usb_<名字>/`）；`ODC_Final/ranking/`、`ODC_Final/medal/` 裡的舊檔也搬走，只留空資料夾。
2. 建好結構（路徑全英文）：
   ```
   ODC_Final/
     problem/   開賽時從主辦桌電拷題目檔
     ranking/   排位賽繳交件（帶分數檔名）
     medal/     金／銅牌賽狀態檔與 session 備份
     backup/    ODC_Program.bundle
   ```
3. 做 bundle（第一節 commit 完才做）：
   ```bash
   git bundle create ODC_Program.bundle --all && git bundle verify ODC_Program.bundle
   ```
   拷到兩支 USB 的 `ODC_Final/backup/`，然後刪掉專案根目錄這份 `ODC_Program.bundle`。

檢查：`find /Volumes/<USB名稱>/ODC_Final -type f` 只印出 `backup/ODC_Program.bundle`。

## 四、出門前：關掉所有 AI 程式

11-09 01:00 在這台 Mac 上看到的 AI 程式：**Claude、ChatGPT（含背景的 Codex）、Cursor、Gemini、Ollama、VS Code（Continue 擴充；新版 VS Code 內建 Copilot 元件）**。另外 `codex`、`agy`（Antigravity）、`ollama` 指令也裝著。Ollama 目前沒有下載模型，但程式在。

我們自己的程式不含任何 AI 呼叫（11-09 查過 `odc/`、`medal/`、`gui/`、`scripts/` 沒有 anthropic／openai／ollama）。金牌賽工具檔名叫 `copilot`、資料夾舊名有 `DRL`，工作人員問起就說：自己寫的軌道力學最佳化程式，不是生成式 AI，沒有連網。

1. **最後才關這個 Claude App**（清理時可能還在用它）。其他先關：
   ```bash
   for a in ChatGPT Cursor Gemini Ollama "Visual Studio Code"; do osascript -e "quit app \"$a\""; done
   pkill -f "codex"; pkill -f "ollama"; pkill -x agy
   ```
2. 比賽中**不要開 VS Code、Cursor**。改 JSON 用 GUI 的設定檔頁或 `nano`；不要用「文字編輯」（會把直引號換成彎引號，JSON 就壞了）。
3. 瀏覽器：關掉所有分頁和視窗（尤其 ChatGPT、Claude、Gemini 網頁）。GUI 開的是 `localhost`，只留那一個分頁。
4. Dock 上的 AI 程式圖示可以拿掉（在圖示上右鍵 → 選項 → 從 Dock 移除），工作人員巡場時一眼就清楚。不用解除安裝。
5. 開「勿擾」，免得通知跳出 AI 程式或訊息。
6. 最後關 Claude App（⌘Q）。

檢查（關完 Claude App 之後，在新開的終端機視窗打）：

```bash
pgrep -ifl "Claude|ChatGPT|Codex|Cursor.app|Gemini|ollama|antigravity|github/copilot|continue"
```

**什麼都沒印**才算完成。有印就照程式名稱 `pkill -f <名稱>` 或從「活動監視器」結束。
（GUI 跑起來後會出現 `copilot.py final ...` 子行程，那是我們的金牌賽工具，這條檢查已經避開它；所以這條要在開 GUI 前打。）

