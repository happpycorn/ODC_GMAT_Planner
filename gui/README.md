# 決賽控制台（GUI）

照手冊一步一步做的本機網頁。按鈕背後跑的就是 [CONTEST_DAY](../docs/ranking/CONTEST_DAY.md) 和
[CONTEST_DAY_FINAL](../medal/CONTEST_DAY_FINAL.md) 上的同一條指令，不改任何求解程式，也不需要網路。

## 開啟

Mac 在 Finder 雙擊 `gui/start.command`；Windows 雙擊 `gui\start.bat`。它會開一個終端機視窗，並在瀏覽器打開 <http://127.0.0.1:8765>。
GUI 用完之前**不要關那個終端機視窗**。

也可以自己在專案根目錄跑：

```bash
uv run python gui/app.py
```

## 用法

- 上方分頁切換**排位賽**、**金／銅牌賽**和**所有工作**（跑過的每一條指令）。
- 左邊是步驟清單，做完的步驟會打 ✅。排位賽的「總覽／下一步」會直接告訴你接下來要做哪一步。
- 每個輸出框上方都有完整指令，旁邊有「複製指令」按鈕。GUI 壞掉的時候，把指令貼到終端機一樣能跑。
- 右上角的時鐘會顯示下一個截止時間：排位賽是手冊的時間盒，金牌賽是全天時程。
- 金牌賽「每回合」頁有 10 分鐘計時器，會標出現在該做哪一段。

### 排位賽

| 步驟 | GUI 做的事 |
|---|---|
| 1 | 建 `configs/local/ranking.json`、填根數。「核對欄」讓隊友 A 不看答案再打一次，不一樣的格子會變紅 |
| 2 | 直接寫入 T_MAX_SEC，或用任務邊界先試算、確認後再寫入 |
| 3 | 計分參數先試算、確認後再寫入 |
| 4 | `check`、`feasibility` |
| 5 | `solve`，自動挑沒用過的目錄名（rank-1、rank-2…），每 2 秒更新 run.log |
| 6 | `retarget`，接著 `verify` |
| 7 | 自動算失格清單，全部通過才可以存 USB，檔名會帶分數 |
| 9 | 一鍵建 SEED=1 或保底設定檔，並切換過去 |

### 金／銅牌賽

一個人照順序做，四個步驟：

| 步驟 | GUI 做的事 |
|---|---|
| 規則與時程 | 設定檔名稱（跟排位賽總覽的設定檔卡片同一套用法；比賽當天用 `day`，彩排或重來換新名字、舊的留著；不是 `day` 時每回合頁會標黃字）、規則重點、公告後 10 分鐘與每回合的時間表 |
| 抄公告與選角色 | 一頁填五項公告（每格選單位，位置速度可貼整列六個數），存成 `day/announced.json`、`day/initial.json`、`day/announce_input.json`；念回卡對照投影片；USB 初始檔拖進來逐格比對；存檔後自動解析並跑角色選擇器；按「我們選躲方／追方」建 session |
| 每回合 | 只有一條路：放回合末狀態檔 → 自動反推雙方 Δv 並核對 → 自動取得建議 → 大字提交行＋X／Y／Z 正負號 → 「照紙上打一次」逐字比對 → 「已交出」。有倒數（放檔自動開始、8:30 轉紅、9:00 跳「現在就交」），6 分鐘建議還沒出來自動改快速版 |
| 故障應變 | 狀況對照表；「備援工具」摺疊區保留舊的規則檔、解析／轉檔／手動 12 格、角色選擇器、建 session 表單 |

放錯檔、船名對調、超過 ΔV_lim 時，錯誤框會說原因並給「換一份檔」「船名對調後重試」「確定用這份（--force）」。
主辦只有口頭 Δv、沒有狀態檔時，用「沒有狀態檔，只有 Δv」。每回合交出的提交行與時刻記在 `day/submissions.json`。

## 注意

- GUI 只在本機 127.0.0.1 上聽，別台電腦連不進來。
- 同一個步驟同時只能跑一個工作。排位賽求解會用滿 CPU，不要同時開兩個。手冊說的「保底設定一起跑」是例外。
- 重新整理瀏覽器不會中斷正在跑的工作。但**關掉終端機視窗會**：正在跑的指令會沒人接手，要重新開 GUI 再跑一次。
- 測試 GUI 時可以設環境變數 `ODC_DAY_DIR` 指到別的資料夾，避免弄髒比賽當天的 `day/`。
